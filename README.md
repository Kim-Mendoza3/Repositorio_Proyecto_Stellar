# Repositorio Proyecto_Stellar

Estructura monolítica del proyecto con documentación centralizada por nivel.

## Estructura Principal

- `docs/`: documentación general del repositorio.
- `SOROBAN/docs/`: reportes técnicos de despliegue y testing.
- `SOROBAN/proyecto-viajes-de-estudio/`: código fuente del proyecto principal.
- `SOROBAN/proyecto-viajes-de-estudio/docs/`: documentación funcional y técnica del subproyecto.

## Puntos de Entrada

- Documentación general: `docs/indice/DOCUMENTACION-INDEX.md`
- Proyecto principal: `SOROBAN/proyecto-viajes-de-estudio/README.md`
- Índice técnico del subproyecto: `SOROBAN/proyecto-viajes-de-estudio/docs/indice/DOCUMENTATION-INDEX.md`
